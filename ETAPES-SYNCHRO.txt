CTRL.APP — ACTIVER LA SYNCHRONISATION
Ce qu'il te reste à faire, dans l'ordre. Compte 10 minutes.
(Le code est prêt et en ligne. Les noms des menus Supabase peuvent changer
légèrement ; si quelque chose ne correspond pas, envoie-moi une capture.)


==============================================================
ÉTAPE 0 — SAUVEGARDE (30 secondes, avant tout)
==============================================================

Sur le Mac où se trouve ton board :
menu ⋮ → « Exporter le board » → range le fichier .json dans iCloud Drive.


==============================================================
ÉTAPE 1 — CRÉER LA BASE (2 minutes)
==============================================================

1. Supabase → ton projet ctrl.app → menu de gauche « SQL Editor ».
2. « New query ».
3. Ouvre le fichier supabase/schema.sql du projet (sur GitHub :
   github.com/axelduvernay/ctrl.app, branche main-486yxj, dossier
   supabase), copie TOUT son contenu et colle-le dans l'éditeur.
4. « Run ». Tu dois voir « Success. No rows returned ».

Ça crée : la table du board, la table des copies quotidiennes, l'espace
privé pour les images et morceaux, et les règles qui font que chaque compte
ne voit que ses propres données.


==============================================================
ÉTAPE 2 — RÉGLER LES ADRESSES (1 minute)
==============================================================

Authentication → URL Configuration :
   - Site URL : https://axelduvernay.github.io/ctrl.app/
   - Redirect URLs → « Add URL », ajoute les deux :
       https://axelduvernay.github.io/ctrl.app/
       http://localhost:4321
   - Save.


==============================================================
ÉTAPE 3 — (CONSEILLÉ) UN CODE DANS LE MAIL (2 minutes)
==============================================================

Par défaut le mail ne contient qu'un lien, qui connecte l'appareil sur
lequel tu l'ouvres. Avec un code, tu peux lire le mail sur ton téléphone
et taper le code sur le Mac.

Authentication → Emails (ou Email Templates) → « Magic Link » :
remplace le contenu par :

   <h2>Connexion à ctrl.app</h2>
   <p>Ton code : <strong>{{ .Token }}</strong></p>
   <p>Ou clique : <a href="{{ .ConfirmationURL }}">se connecter</a></p>

Save.


==============================================================
ÉTAPE 4 — TE CONNECTER SUR LE MAC (le plus important)
==============================================================

FAIS-LE D'ABORD SUR LE MAC QUI A TON BOARD : à la première connexion,
c'est ce board qui part dans le cloud.

1. Ouvre https://axelduvernay.github.io/ctrl.app/ et fais ⌘⇧R.
   Le menu ⋮ doit afficher en bas « v07.10 · synchro ».
   (Si ton board est sur localhost:4321, fais d'abord git pull puis
   python3 serve.py, et connecte-toi là.)
2. Menu ⋮ → « Se connecter… » → ton adresse → « Recevoir le lien ».
3. Ouvre le mail : clique le lien sur le Mac, ou tape le code.
4. Message « Board enregistré dans le cloud ». Un petit point vert apparaît
   sur le bouton ⋮ : synchronisé.

Le point : vert = synchronisé, orange = en cours, gris = hors ligne,
rouge = erreur (nouvel essai automatique).


==============================================================
ÉTAPE 5 — FERMER LES INSCRIPTIONS (30 secondes)
==============================================================

Maintenant que ton compte existe :
Authentication → Sign In / Providers (ou Settings) →
désactive « Allow new users to sign up » → Save.

Plus personne d'autre ne peut créer de compte sur ton app.


==============================================================
ÉTAPE 6 — LES AUTRES ORDINATEURS
==============================================================

Ouvre le site, menu ⋮ → « Se connecter… », même adresse.
Ton board arrive, images comprises. Le board d'accueil de cet appareil
n'est pas mélangé au tien.


==============================================================
À SAVOIR
==============================================================

- Envoi de mails limité par Supabase (quelques-uns par heure) : si
  « Trop d'envois », attends un peu.
- Chaque appareil reste connecté : tu ne le fais qu'une fois par appareil.
- Hors ligne, tout marche ; la synchro reprend au retour du réseau.
- Une copie du board est gardée chaque jour pendant 30 jours.
- Ne JAMAIS donner : la clé « service_role » / « secret », le mot de passe
  de la base.
